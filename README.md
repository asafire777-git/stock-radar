# 📈 Stock Radar (AI 주식 급등 & 신규상장 분석 레이더)

네이버 금융 실시간 시세, 한국거래소(KRX) 수급 데이터, 기술적 차트 지표 퀀트 점수 및 머신러닝 모델을 결합하여 상승 유력 종목을 스크리닝하고 분석하는 통합 주식 분석 시스템입니다.

> **독립 실행 폴더**: 본 프로젝트는 기존 아우라(Aura) 마케팅 포털과 완전히 격리된 독립 가상환경(`venv`)에서 구동됩니다.

---

## 🌟 주요 기능

1. **🔥 실시간 급등주 TOP 100**
   - 네이버 금융 실시간 급등/거래량 폭발 종목 수집
   - 코스피 / 코스닥 시장별 필터링 및 상승률 실시간 모니터링
2. **🚀 신규 상장주 레이더 (New Listings)**
   - 최근 1~24개월 이내 신규 상장 종목 자동 추출
   - 상장일, 경과일수, 가격 변동성 추적
3. **⭐ AI 퀀트 & 머신러닝 추천 TOP 20**
   - **모멘텀 (30점)**: 당일 및 최근 주가 탄력도
   - **거래대금 (25점)**: 시장 유동성 집중도 (100억~1,000억+)
   - **차트 패턴 (25점)**: 이평선 정배열(5>20>60>120), 볼린저밴드 상단 돌파, 5일/20일 골든크로스, RSI 모멘텀
   - **수급 (20점)**: 최근 외국인 / 기관 3일 누적 양매수 여부
   - **머신러닝 상승 확률 예측**: 향후 5거래일 내 +5% 이상 상승할 확률(%) 산출
4. **📊 종목 정밀 진단실**
   - Plotly 인터랙티브 캔들 차트 (한국식 빨강 양봉 / 파랑 음봉)
   - 이동평균선(5/20/60일) 및 볼린저 밴드
   - 거래량 및 RSI(14) 보조지표
   - 최근 20거래일 외국인/기관 순매수 추이 막대그래프
   - AI 핵심 포착 패턴 진단 요약

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (추천)
`stock-radar` 폴더 내의 **`run.bat`** 파일을 더블 클릭하면 자동으로 가상환경이 켜지고 웹 브라우저(`http://localhost:8501`)가 열립니다.

### 방법 2. 터미널 수동 실행
```bash
cd c:\AIproject\Sample\stock-radar
.\venv\Scripts\activate
streamlit run app.py
```
